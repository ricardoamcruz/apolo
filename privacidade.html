Política de privacidade

A.U.R.O.R.A., módulo do assistente A.P.O.L.O. · Atualizada em 17 de novembro de 2026

O que a A.U.R.O.R.A. é

Um programa de uso pessoal que roda no computador do próprio usuário. Não existe servidor da A.U.R.O.R.A.: tudo acontece na máquina de quem a instalou.

Quais dados do Google ela acessa

Somente a permissão youtube.readonly, de leitura: a lista de playlists do usuário, as músicas dessas playlists e, se não houver playlist adequada, a lista de vídeos curtidos. Ela não publica, altera, apaga nem comenta nada na conta.

Como os dados são usados

Para sortear uma música e tocá-la no player oficial do YouTube, visível na tela. Nenhum áudio ou vídeo é baixado. Os dados não são usados para publicidade, perfilamento, treinamento de modelos de IA nem qualquer outra finalidade.

Onde ficam guardados

Apenas no computador do usuário: o token de acesso fica num arquivo legível só pelo próprio usuário, e a lista de músicas fica em cache local por até um dia. Nada é enviado a servidores próprios ou de terceiros, além das chamadas à API do próprio Google.

Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Apagar a pasta ~/.apolo/aurora remove tudo o que ficou no computador.
